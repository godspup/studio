❓ ПОМОЩЬ ПО СЕКВЕНСОРУ

▶ НАЧАЛО▼

Что это

Пошаговый секвенсор в браузере. Ставишь ноты и удары по сетке, играет синтезированными инструментами. Плюс запись битбокса через микрофон — удары ртом автоматически раскладываются по дорожкам.

Быстрый старт

  • Жми + внизу сетки → откроется библиотека инструментов
  • Клик по клетке = поставить ноту. Ещё раз = убрать
  • Жми ▶ ИГРАТЬ или Space
  • Крути СВИНГ и ХЬЮМ для грува
  • Экспорт JSON → сохранить паттерн
▶ ТРАНСПОРТ▼

▶ ИГРАТЬ / ■ СТОП

Запуск и остановка воспроизведения. На клавиатуре — Space.

⏮ В НАЧАЛО

Возвращает playhead на первый шаг.

БПМ

Темп 40..300 BPM. Один шаг = 1/16 ноты. Стрелки ↑ ↓ — ±1, Shift+стрелки — ±5.

Смена BPM на ходу: уже звучащая нота доигрывает в старом темпе (~0.1 сек), следующие идут в новом. Ранее поставленные события пересчитываются автоматически — ничего не съезжает.

🎵 МЕТРО

Метроном. Акцент на первой доле бара (1600 Гц), тише на остальных долях (1000 Гц).

Другие клавиши

  • ← → — сдвиг playhead на шаг. Shift = бит, Ctrl = бар
  • Home / End — в начало / конец
  • + / − — BPM ±1
  • Del — очистить текущий шаг
  • Esc — стоп
▶ СЕТКА И ВИД▼

ШАГОВ

Сколько всего шагов в паттерне, 4..512. Дефолт — 128. Кнопки-пресеты ниже — 16/32/64/128.

РАЗМЕР (зум)

Размер одной клетки, 10..32 px. Крути ползунок — вся сетка перерисуется.

⊟ СВЕРНУТЬ

Прячет ручки громкости / панорамы / тона у дорожек. Удобно на мобиле чтобы больше места под сетку.

◉ СЛЕЖЕНИЕ

Авто-скролл сетки за playhead. Отключи если хочешь сам рулить скроллом.

Playhead

Зелёная вертикальная линия. Можно тянуть пальцем — двигает позицию воспроизведения.

▶ СВИНГ И ХЬЮМ▼

СВИНГ

Сдвигает нечётные шаги (2-й, 4-й, 6-й...) вправо на долю от длительности шага. 0 = ровно, 0.7 = максимальный сдвиг (70% шага).
Даёт «качание» — как в хип-хопе и джазе. Без свинга 16-е идут ровно, с свингом — «тик-так-тик-так», вторая из пары догоняет первую.

ХЬЮМАНАЙЗ

Случайный сдвиг каждой ноты по времени (±6 мс) и по громкости (±17%).
Убирает «машинность», делает паттерн живым. На 0 — идеально ровно, на 1 — сильно размазано.

▶ РЕДАКТИРОВАНИЕ СЕТКИ▼

Клик по клетке

  • Пусто → ставит ноту в этот шаг
  • Уже есть → убирает ноту
  • В мелодичной дорожке (BASS/LEAD/PAD/CHORD/MALLET) ставит ноту с базовым питчем дорожки

Разворот в piano roll

Кнопка ♪ в шапке мелодичной дорожки (BASS / LEAD / PAD / CHORD / MALLET). Разворачивает дорожку в piano roll — 12 полутонов по вертикали. Повторное нажатие (▾) сворачивает обратно.

Клик по имени дорожки

Превью звука текущего инструмента этой дорожки.

Кнопка + внизу

Открывает библиотеку инструментов. Категории сверху (KICK/SNARE/...), пресеты внутри.

▶ КЛИПЫ (ПРЯМОУГОЛЬНИКИ)▼

Каждая нота в сетке видна как цветной прямоугольник поверх клеток. Цвет = цвет дорожки.

  • Тап по клипу — удалить
  • Движение вбок — растянуть/сжать длительность
  • Долгое удержание (350мс) + движение — перетащить (в т.ч. на другую дорожку по вертикали)
  • Если выделено несколько — тянешь один, едут все
▶ ВЫДЕЛЕНИЕ И COPY/PASTE▼

▭ ВЫДЕЛИТЬ

Режим рамки. Включаешь кнопку → тянешь мышью/пальцем по сетке → пунктирная рамка. Отпустил — все клипы, попавшие в рамку, выделились зелёным контуром.

⇅ ДВИГАТЬ

Режим перемещения дорожек. Включаешь кнопку — у дорожек слева скрываются кнопки (mute / solo / ×) и ползунки громкости, панель становится ручкой. Тапаешь и тянешь дорожку вверх/вниз — она переезжает. Целевая позиция обводится зелёным пунктиром. Клик по названию инструмента в этом режиме не проигрывает звук. Выключи — вернётся обычный вид.

COPY

Копирует выделенные клипы в буфер обмена (в памяти). После этого панель переключается на режим вставки.

PASTE

Тапни место вставки → там появится жёлтый маркер → жми PASTE. Клипы вставятся относительно маркера, сохраняя структуру группы.

× (сброс)

Сбрасывает буфер обмена и снимает выделение.

Тап по пустому месту

Просто снимает выделение, если что-то было выделено.

▶ ДОРОЖКИ▼

M — MUTE

Заглушить дорожку. Ноты играются, но не слышны.

S — SOLO

Играет только эта дорожка, все остальные глушатся. Если несколько solo — играют все solo.

× — удалить дорожку

Удаляет дорожку и все её события.

ГРОМК / ПАНО / ТОН

  • ГРОМК — общая громкость дорожки, 0..1
  • ПАНО — стерео-позиция, -1 (лево) .. +1 (право)
  • ТОН — общий питч дорожки, 0.5..2

1-9

Быстрый mute/unmute дорожек по счёту сверху вниз.

▶ PIANO ROLL▼

Кнопка ♪ у мелодичной дорожки

Появляется у BASS / LEAD / PAD / CHORD / MALLET. Разворачивает дорожку в piano roll высотой 12 полутонов.

Высота строк

Снизу вверх: C, C#, D, D#, E, F, F#, G, G#, A, A#, B. Чёрные клавиши затемнены. 12 полутонов = одна октава.

Клик по клетке piano roll

  • Пусто на этой высоте → ставит ноту
  • Уже есть нота на этой высоте → убирает её
  • На одном шаге могут быть несколько нот — это аккорд. Просто тыкай в разные строки на одном шаге

▾ свернуть

Возвращает дорожку в компактный однострочный вид.

В компактном виде на одном шаге хранится весь аккорд, но показан как одна клетка. Клик по ней убирает все ноты шага.

▶ БИТБОКС▼

▶ МИК

Включает микрофон. Слушай свои удары ртом — приложение классифицирует их и ставит в сетку.

Не работает через file:// — нужен http://localhost или https. Только Chrome/Edge/Safari свежие.

🔊 ЗВУК

Вкл/выкл звук секвенсора. Глуши когда пишешь в мик, чтобы звук из колонок не попадал обратно в микрофон.

авто-мьют

При старте мика глушит секвенсор автоматически.

ЧУВСТВ / ПОРОГ

  • ЧУВСТВ — множитель порога, 0.5..4. Меньше = чувствительнее, ловит тихие удары
  • ПОРОГ — абсолютный уровень, 0.005..0.15

🎤 ДИАГА

Отдельная страница для обучения шаблонов. Учишь приложение как звучит именно твой «пу» или «тц».

↻ ШАБЛОНЫ / 🗑 СБРОС

Перечитать / удалить все обученные шаблоны (хранятся в localStorage).

Маршрутизация KICK/SNARE/HAT/БАС/МЕЛОД

Какая дорожка отвечает за какой распознанный звук. Если у тебя 3 кика — выбери какой использовать.

ГАММА

Квантование мелодийных нот в выбранную гамму: мажор / минор / пентатоника. Распознанная нота автоматически прилипает к ближайшей в гамме.

▶ TAP-КЛАВИШИ▼

Клавиши K S H C B ставят удар/ноту в текущий шаг playhead:

  • K → KICK
  • S → SNARE
  • H → HAT
  • C → CLAP
  • B → BASS

Работает всегда, даже без включённого микрофона. Играет сразу, ставит в сетку.

▶ ЗВУКИ▼

Все звуки — чистый синтез, без сэмплов.

KICK / CLAP / HAT

Переделаны в новой версии. Кики — sine-суб + шумовой клик (без пискли). Клэпы — серия burst'ов + тональное «мясо» + короткий хвост. Хэты — чистый шум через highpass, без «звенящего» metal-слоя.

OLD

Старые кики/клэпы/хэты — для ностальгии. По звуку как было до переделки.

SNARE / PERC / BASS / LEAD / PAD / FX / CHORD / MALLET

Не тронуты. Внутри у каждой категории несколько пресетов (напр. BASS: saw, reese, wobble, acid, fm...).

▶ ЭКСПОРТ / ИМПОРТ▼

📤 ЭКСПОРТ

Сериализует паттерн в JSON v2. Что сохраняется: BPM, число шагов, режим, все события (время, длительность, питч), все дорожки (id, громкость, панорама, тон, mute, solo, шаги, питчи).

📥 ИМПОРТ

Вставь JSON в текстовое поле внизу → жми ИМПОРТ. Паттерн заменится целиком.

Клипы, piano-roll-ноты, аккорды — всё сохраняется.

▶ СЛОВАРЬ ТЕРМИНОВ▼
ШАГ (step)
Минимальная клетка сетки. Один шаг = 1/16 ноты. При 120 BPM и размере 4/4 один шаг длится 125 мс. Дефолт — 128 шагов = 8 баров.
ДОЛЯ (beat)
4 шага = 1 доля. Клетки с долей подсвечены в сетке. В нотации это «четверть».
БАР (bar, такт)
16 шагов = 1 бар = 4 доли. Нумерация баров показана цифрами (1, 17, 33...) в шапке сетки.
BPM
Beats Per Minute — удары в минуту. Темп. 120 BPM — стандарт для хип-хопа, 174 — drum and bass, 90 — boom bap.
PLAYHEAD
Зелёная вертикальная линия в сетке. Показывает текущую позицию воспроизведения. Двигается с интерполяцией по реальному аудио-времени, поэтому не дёргается при лагах.
КЛИП
Прямоугольник поверх сетки = одна нота/удар. У него есть позиция (time), длительность (dur) и высота (pitch). Тянешь вбок — меняешь длительность. Долгое удержание + движение — перемещаешь.
СОБЫТИЕ (event)
Внутренний формат данных. Каждое событие = { id, trackIdx, time, dur, pitch }. Всё, что ты ставишь в сетку, живёт как события. Экспорт JSON сохраняет их.
СВИНГ (swing)
Сдвиг нечётных шагов вправо. Ритм «тик-так» вместо ровного «тик-тик». 0 = ровно. 0.2-0.4 = лёгкий грув. 0.6-0.7 = сильное качание. Классика для boom bap и джаза.
ХЬЮМАНАЙЗ (humanize)
Авто-«очеловечивание». Каждая нота случайно сдвигается по времени (±6 мс) и по громкости (±17%). Убирает машинное звучание. На 0 — идеальный квант, на 1 — заметное «живое» размазывание.
SNAP
Прилипание к сетке. У нас включено всегда для позиции вставки при PASTE. Вставленный блок клипов попадает на ровный шаг.
ЛАСО (рамка выделения)
Способ выделить сразу несколько клипов. Включаешь кнопку ▭ ВЫДЕЛИТЬ → тянешь прямоугольник → все клипы внутри выделяются.
MUTE (M)
Заглушить дорожку. Ноты продолжают играть, но без звука. Используется для примера «а вот если убрать хэт».
SOLO (S)
Играет только эта дорожка. Все остальные временно глушатся. Если несколько solo одновременно — играют только solo-дорожки.
ГРОМКОСТЬ (vol)
Уровень сигнала дорожки, 0..1. Влияет на громкость всех нот дорожки. Меняется ползунком в шапке дорожки.
ПАНОРАМА (pan)
Позиция в стерео, -1 (лево) .. +1 (право). 0 = центр. Разносит инструменты в стороны для «ширины» микса.
ТОН (pitch)
Множитель частоты дорожки, 0.5..2. 1 = как есть, 2 = октава выше, 0.5 = октава ниже. В мелодичных дорожках работает как транспозиция всех нот.
ПОЛУТОН
Минимальный шаг между нотами в западной музыке. Один полутон = коэффициент 2^(1/12) ≈ 1.0595. Октава = 12 полутонов = множитель 2.
PIANO ROLL
Развёрнутый вид дорожки, где по вертикали — 12 полутонов (высота ноты), по горизонтали — время. Стандарт для редактирования мелодий в DAW.
АККОРД
Несколько нот одновременно на одном шаге. В нашем piano roll просто тыкаешь в несколько клеток по вертикали на одном шаге — все они зазвучат вместе. Пример: C + E + G = мажорный аккорд.
СИНТ (синтезатор)
Программный генератор звука. У нас 14 видов: kick, snare, clap, hat, tom, cymbal, perc, bass, lead, pad, fx, chord, mallet, плюс old для старых. Каждый синт — набор параметров, генерирующих осцилляторы, шум, фильтры.
БИТБОКС
Воспроизведение ударных ртом. Приложение слушает микрофон, анализирует спектр (FFT), ZCR и питч, классифицирует удар как kick/snare/hat/clap/bass/melody и ставит в сетку.
ШАБЛОН БИТБОКСА
Записанный «отпечаток» твоего удара. Обучаешь в ДИАГЕ — 5 раз бьёшь один и тот же слог, приложение усредняет характеристики и запоминает. Потом при распознавании сравнивает со всеми шаблонами.
ГАММА
Набор нот, в который укладывается мелодия. Мажор — весёлая, минор — грустная, пентатоника — восточная/блюзовая. Распознанная нота битбокса автоматически сдвигается к ближайшей в выбранной гамме.
JSON ЭКСПОРТ
Формат сохранения паттерна. Читаемый текстовый файл с BPM, дорожками, событиями. Можно скопировать в чат, сохранить как файл, отправить другу.
